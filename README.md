# 中国科技论坛投稿适配度分析系统（MVP）

面向中文学术论文作者的投稿前分析工具，提供：
- 期刊画像
- 近期主题趋势
- 论文上传解析（docx/pdf/txt）
- 编辑视角评分（100分，8维度）
- 接收概率区间估计
- 可点击逐条修改建议（右侧详情面板）
- 报告导出（Markdown / HTML）

> 免责声明：本系统给出的接收概率为模型化估计，不代表期刊官方意见，不构成录用承诺。

## 1. 安装依赖

```bash
npm install
```

## 2. 启动项目

```bash
npm run dev
```

打开：`http://localhost:3000`

## 3. 配置 ANTHROPIC_API_KEY（可选）

1. 复制环境变量文件：
```bash
cp .env.example .env.local
```
2. 在 `.env.local` 中填写：
```env
ANTHROPIC_API_KEY=your_key_here
```

未配置时，系统自动使用内置规则评分引擎。

## 4. 上传论文

进入“上传论文”页面，支持：
- `.docx`
- `.pdf`
- `.txt`

系统将自动解析：标题、摘要、关键词、章节、参考文献，并生成评分与建议。

## 5. 导出报告

进入“分析报告”页面，可导出：
- Markdown
- HTML

## 6. 手动导入《中国科技论坛》近期文章样本

MVP 已内置示例主题数据（`data/zgkjlt_topics.json`）。
若官网抓取失败，可使用两种方式：
1. 直接编辑 `data/zgkjlt_topics.json` 覆盖样本数据。
2. 调用 `POST /api/journal/import`，提交目录页 HTML 字符串进行标题提取。

## 7. 目录结构（关键）

- `app/`：页面与 API Routes
- `components/`：侧栏、顶部状态栏
- `lib/`：解析器、评分引擎、主题分析、AI provider
- `types/`：核心 TypeScript 类型
- `data/`：期刊画像与示例主题
- `prisma/`：后续数据库持久化预留

## 8. 核心规则评分维度（100分）

1. 主题契合度（20）
2. 问题意识（15）
3. 理论贡献（15）
4. 研究设计（15）
5. 论证逻辑（10）
6. 语言表达（10）
7. 格式规范（10）
8. 期刊风格匹配度（5）

## 9. 安全与合规说明

- 不保证录用
- 不生成虚假参考文献
- 不鼓励伪造数据
- 仅在本地分析上传内容；仅在用户配置 API Key 后才会调用外部模型
- 官网抓取失败时建议手动导入，不绕过网站限制
